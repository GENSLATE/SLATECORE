# Microsoft Edge WebView2 Runtime (Fixed Version)

This notice goes into the optional `slatecore-launcher-<version>-webview2-runtime.zip` of
SLATECORE LAUNCHER by GENSLATE.

The folder `other\shared\webview2\<version>-x64\` holds the Fixed Version of the Microsoft Edge
WebView2 Runtime, copied unmodified from the package Microsoft publishes. It is Microsoft's
software, not GENSLATE's. `runtime.json` in that folder records the version, the file name and
address it came from and the SHA-256 of the package.

- **License.** The runtime is licensed to you under the Microsoft Software License Terms for the
  Microsoft Edge WebView2 Runtime, which Microsoft shows on its WebView2 download page. Read
  them there; they apply to your use of the runtime, and GENSLATE does not change them.
- **Source.** The package is taken only from Microsoft. Do not replace it with a copy from
  another site.
- **Data.** WebView2 sends required diagnostic data to Microsoft, and optional data when
  Windows diagnostic data is switched on. The launcher cannot turn this off.
- **Use.** SLATECORE LAUNCHER uses this runtime only when the PC has no suitable WebView2 of its
  own. Delete the folder to go back to the PC's runtime.
