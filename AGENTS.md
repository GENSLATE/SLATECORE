# SLATECORE: rules for every agent

Turborepo + bun + Cargo monorepo, Windows only. The full rewrite of this file lands with the agent-folder setup; until then these golden rules apply.

## Golden rules

1. **bun only.** `bun install`, `bun run <script>`, `bun x --no-install <bin>`, `bun test`. Never npm, npx, pnpm, yarn or node.
2. **Windows only.** Target `x86_64-pc-windows-msvc`. No macOS or Linux code paths, targets or assets.
3. **No agent credit.** Commits and PRs carry no `Co-Authored-By`, `Made-with`, "Generated with" footers, session links or agent names. Conventional Commits (`type(scope): subject`).
4. **Generated files are never edited by hand.** Token outputs (`packages/tokens/src/generated/**`, `crates/design-tokens/src/generated/**`), `*.generated.ts`, `src-tauri/gen/**`, `permissions/autogenerated/**`, `bun.lock` and `Cargo.lock` come from their generators (`bun run tokens`, `bun install`, cargo).
5. **Leave no trace.** Nothing the launcher controls is written outside its installDir: configs, cache, logs, database, WebView2 data and TEMP all live inside it. No autostart, no registry writes, no OS-folder fallback, no absolute paths persisted.

## Names

GENSLATE is the developer and publisher, SLATECORE the suite and this monorepo, SLATECORE LAUNCHER the product. Always in capitals in user-visible text. The code namespace stays GENSLATE: `@genslate/*` packages, `genslate-*` crates, `xyz.genslate.*` identifiers.

## Layout

- `crates/{paths,design-tokens,launcher-core,vault,testing}`: Rust library crates (no `package.json`; Rust tasks run at the root as `//#rust:*`).
- `packages/{tokens,design-system,tauri-bridge,config-typescript,config-vite}`: shared TypeScript packages.
- `programs/desktop/launcher`: the Tauri app. `programs/webapp/example`: the SLATECORE Design Kit.
- `scripts/commands/<name>.ts`: one file per root `bun run <name>` command.

Turborepo docs for the pinned version are in `node_modules/turbo/docs/README.md`.
